Opção 1: Executar chamando o pacote completo (Mais rápido)
Rode o comando especificando a CLI do Capacitor:

PowerShell
npx @capacitor/cli init "TESTE Agenda" "br.com.teste.agenda" --web-dir "dist"
Opção 2: Garantir a instalação local e executar em seguida
Se a Opção 1 pedir confirmações extras, instale o pacote de desenvolvimento primeiro:

PowerShell
npm install -D @capacitor/cli
npx cap init "TESTE Agenda" "br.com.teste.agenda" --web-dir "dist"
Assim que o comando finalizar, o arquivo de configuração capacitor.config.ts (ou .json) será criado na raiz do projeto.

Depois disso, você já pode dar sequência adicionando a plataforma do Android:

PowerShell
npm install @capacitor/android
npx cap add android
